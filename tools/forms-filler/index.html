Checking whether this browser can run the private model…

    This page reads a form and your papers on this computer. You choose which values to keep. A desktop browser extension can fill another website from a file you export. It is not in the Chrome Web Store, and this page cannot install it for you.

    Downloading private model

    Install the browser extension

    Desktop Chrome or Chromium only. Not a phone install, not a one-click install, and not a Chrome Web Store listing. Version 0.1.1. The zip is the unpacked extension. Nothing in it is uploaded.

    Download the extension (version 0.1.1)

    1. Download the zip and unzip it. Keep the folder intact.
    2. Open the browser’s Extensions page. Turn on Developer mode. Choose Load unpacked, then select that unzipped folder.
    3. Pin “Forms Filler profiles” so you can find the icon. On a new browser profile the shortcut Ctrl+Shift+Y (Command+Shift+Y on a Mac) opens it too.
    4. Open Saved values on this page, confirm the values you want, and use Export confirmed values.
    5. In the extension, import that file, choose the person, read Preview, then Fill. Fill writes the checked values into that website immediately. The site can read or save them even though Fill does not press submit.

    This site and the extension keep separate copies. Removing the imported copy in the extension does not delete values here. To refresh the extension, export again and import the new file. Password, payment, and one-time-code fields are skipped, as are hidden, disabled, and read-only fields. The extension may use the tab you open, run on that tab when you press Fill, and store the imported copy. It does not ask to read every website.

    Saved values

    Stored in this browser only. Not an account and not synced. On a shared computer, clear them when you are done. Unconfirmed reads stay here until you confirm them. The extension uses confirmed values only, from an export file you download yourself.
